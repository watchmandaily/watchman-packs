# Watchman Media language packs

Static language packs (UI strings and scripture text) for Watchman Media apps (Prophecy Pulse, Daniel Unsealed), served by GitHub Pages at https://watchmandaily.github.io/watchman-packs/<app>/manifest.json.

## Scripture sources and licenses

- **Arabic (ar)**: public-domain. Smith-Van Dyck Arabic Bible (1865), public domain. Text: eBible.org arb-vd (https://ebible.org/find/details.php?id=arb-vd), translated by the Syrian Mission, contributed by the American Bible Society
- **German (de)**: public-domain. Luther 1912, public domain. Text: eBible.org deu1912 (https://ebible.org/find/details.php?id=deu1912)
- **Spanish (es)**: public-domain. Reina-Valera 1909, public domain. Text: eBible.org spaRV1909 (https://ebible.org/find/details.php?id=spaRV1909)
- **French (fr)**: public-domain. Louis Segond 1910, public domain. Text: eBible.org fraLSG (https://ebible.org/find/details.php?id=fraLSG)
- **Hindi (hi)**: CC BY-SA 4.0. Indian Revised Version (IRV) Hindi 2019, copyright © 2017, 2018, 2019 Bridge Connectivity Solutions Pvt. Ltd. Licensed under CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/). Text: eBible.org hin2017 (https://ebible.org/find/details.php?id=hin2017). Changes: footnotes and cross-references removed; arranged in KJV verse numbering (Rev 1:17-18, Rev 12:18 + 13:1). Not endorsed by the licensor.
- **Chinese (zh)**: public-domain. Chinese Union Version, Mandarin (官話和合譯本), 1919 first edition, public domain. Text: Chinese Wikisource (https://zh.wikisource.org/wiki/聖經_(和合本)), converted to simplified characters (OpenCC t2s + hand fixes); cross-checked with bible.fhl.net cumv

The Hindi IRV text is licensed under CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/); the Hindi pack files are shared under the same license. Portuguese (Almeida 1911) is GPL; see below. All other scripture texts here are public domain. UI strings © Watchman Media.
